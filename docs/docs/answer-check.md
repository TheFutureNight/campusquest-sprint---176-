# Проверка ответа

## Зачем нужна
Функция проверяет ответ игрока и сообщает результат.

## Пользовательский сценарий
1. Игрок вводит ответ.
2. Нажимает кнопку «Проверить».
3. Получает сообщение о правильном или неправильном ответе.

## Критерий готовности
- Правильный ответ засчитывается.
- Неправильный ответ не засчитывается.
- Игрок получает сообщение о результате.
- Пустой ответ не принимается.

## Риск или вопрос
Нужно уточнить, сколько попыток даётся на одно задание.
