# Карточка загадки 
 
## Зачем нужна 
Карточка показывает текст задания и позволяет игроку ввести ответ. 
 
## Пользовательский сценарий 
1. Игрок выбирает станцию. 
2. Читает текст загадки. 
3. Вводит ответ и нажимает «Проверить». 
 
## Критерий готовности 
- Текст задания отображается полностью. 
- Есть поле для ввода ответа. 
- Есть кнопка проверки. 
 
## Риск или вопрос 
Нужно уточнить, учитываются ли регистр и лишние пробелы в ответах.
