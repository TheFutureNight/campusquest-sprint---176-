# Стартовый экран и список станций

## Зачем нужна
Стартовый экран помогает игроку начать квест, а список станций показывает доступные задания.

## Пользовательский сценарий
1. Игрок открывает CampusQuest.
2. Нажимает кнопку «Начать квест».
3. Выбирает доступную станцию.

## Критерий готовности
- Есть кнопка «Начать квест».
- Отображается список станций с названиями и статусами.

## Риск или вопрос
Нужно уточнить, открываются ли станции по порядку.
